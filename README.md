#ATM Transactions Analysis Dashboard (Power BI)
## 🏁 Project Objective

This project aims to analyze and visualize ATM transaction performance across different Indian states using Power BI.
The dashboard provides insights into transaction trends, cost maintenance, and revenue performance — helping stakeholders monitor ATM uptime, profitability, and cost distribution efficiently.

## 📌 Problem Statement
 - Banks and ATM operators often manage large volumes of transaction and maintenance data from multiple regions. Without a centralized analytical view, it becomes difficult to:
 - Monitor ATM uptime and performance.
 - Identify revenue trends by region.
 - Track operational costs and maintenance efficiency.
 - Compare financial vs. non-financial transactions over time.
 - This Power BI dashboard provides a comprehensive, interactive solution — centralizing all metrics into one interface for clear analysis and decision-making.

## 🚀 Key KPIs
 - Total Cost – Overall ATM operational cost.
   
 - Average Total Transactions (AVG TXN) – Mean transaction volume across ATMs.
   
 - Gross Profit % – Profitability ratio per ATM or region.
   
 - Average Uptime % – ATM operational uptime efficiency.
   
 - Average eBill – Electronic billing average per ATM.

##📈 Dashboard Sections
 ->1️⃣ Home Page

 - Introductory view with project name and quick navigation buttons (Home, Dashboard, Detail).

 - Illustrative graphic representing ATM usage and customer interaction.

 - Social links for project author.

 -> 2️⃣ Dashboard Page – Cost & Transaction Overview

 - Cost Analysis – Displays monthly maintenance and repair costs.

 - Revenue Metrics – ATM, MHA, and Monthly Revenue comparisons by state.

 - Transaction Analysis – Financial vs. Non-Financial transactions across months.

 - Performance Summary KPIs – Total Cost, Avg TXN, Profit %, Uptime %, and Avg eBill.

 - Trend Graph – Transaction trends by date.

 -> 3️⃣ Detail Page – Range and State-Level Performance

 - Range Analysis – Margin and transaction range comparison between current and previous months.

 - Detailed Table View – Displays:

 - Revenue performance by state

 - Average transactions

 - Gross profit percentage

 - ATM uptime by site type (Captive, DBT, Regular, Tea Estate)
